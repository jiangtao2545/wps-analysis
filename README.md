# 文档操作日志-二级公司月度用户数统计需求文档（含导出格式）
## 一、需求概述
基于**MySQL分月日志表**和**用户表**，结合外部公司CSV文件，开发SpringBoot2+JDK8+MyBatis-Plus应用，**按月统计各二级公司的活跃用户总数**（统计维度：操作日志的所属用户+归属二级公司），并支持按指定格式**导出Excel报表**。

## 二、数据库表说明
### 1. 文档操作日志表（分表存储）
- 表名规则：`log_doc_yyyy_MM`（按自然月分表，如 log_doc_2025_06、log_doc_2025_07）
- 核心关联字段：`operator_id` = 用户表 `userid`（一一对应）
- 核心关键字段：企业ID(`comp_id`)、操作人ID(`operator_id`)、操作时间(`operation_time`)、操作类型等
- 主键：`id`；索引：`idx_c(comp_id)`

### 2. 用户表
- 表名：`user`
- 核心关联字段：
  - `userid` → 日志表 `operator_id`
  - `login_name` → 公司CSV文件 `loginname` 列
- 核心关键字段：企业ID(`comp_id`)、登录名(`login_name`)、用户状态、部门信息等

## 三、外部数据文件
- 文件名称：公司表.csv
- 核心列：
  - `loginname`：对应用户表 `login_name`
  - `company`：二级公司名称（统计核心维度）

## 四、核心统计逻辑
1. **数据关联关系**
   日志表操作人ID → 用户表用户ID → 用户表登录名 → CSV文件登录名 → 二级公司
2. **统计口径**
   按**自然月**分组，统计**每个二级公司**下，**当月产生文档操作日志的去重用户总数**
3. **统计结果字段**
   统计月份、二级公司名称、月度活跃用户数

## 五、技术栈要求
- 开发框架：SpringBoot 2.x
- JDK版本：JDK 8
- ORM框架：MyBatis-Plus
- 数据库：MySQL 5.7+
- 报表工具：**EasyExcel/POI**（Excel导出）
- 辅助工具：CSV文件解析、时间处理、分页/结果导出

## 六、程序核心功能
1. **CSV文件加载**
   启动/执行时加载公司表.csv，建立`loginname → 二级公司`映射缓存
2. **动态分表查询**
   根据统计月份，自动匹配对应`log_doc_yyyy_MM`日志表
3. **数据关联统计**
   关联日志表 + 用户表 + CSV映射关系，完成去重用户统计
4. **报表导出功能（核心）**
   支持按指定格式导出**Excel文件**，字段自动匹配二级公司

## 七、导出格式要求（固定版式）
### 1. 导出文件格式
- 文件类型：**Microsoft Excel 2007+ (.xlsx)**
- 文件命名：`二级公司月度用户统计_yyyyMMddHHmmss.xlsx`（带时间戳）

### 2. 表格表头与数据格式（固定）
| 月份   | A公司 | B公司 | C公司 | ...（所有二级公司动态列） |
| ------ | ----- | ----- | ----- | ------------------------ |
| 2025年1月 | 数值  | 数值  | 数值  | 数值                     |
| 2025年2月 | 数值  | 数值  | 数值  | 数值                     |
| 2025年3月 | 数值  | 数值  | 数值  | 数值                     |

### 3. 格式规则
1. **第一列固定为「月份」**，格式：`yyyy年MM月`（如 2025年1月）
2. **后续列动态生成**：读取CSV中所有不重复的**二级公司名称**作为列名（A公司、B公司、C公司...）
3. **单元格数值**：对应月份+对应二级公司的**去重活跃用户数**，无数据则填 `0`
4. **行数据**：按时间正序排列（1月→2月→3月...）
5. 支持**自定义时间范围导出**（如近6个月、近12个月、自定义起止月份）

## 八、非功能要求
1. 兼容跨月份、跨年分表查询
2. 大数据量下保证查询性能（利用现有索引+分表特性）
3. CSV文件路径可配置，支持热加载/重新加载
4. 导出响应速度快，支持大数据量流式导出（避免OOM）
5. 导出文件样式规范：表头加粗、边框完整、列宽自适应

---

### 总结
1. 核心目标：**按月统计各二级公司活跃用户数 + 按固定矩阵格式导出Excel**
2. 导出格式：**月份为行、二级公司为列**的交叉统计表
3. 技术栈：SpringBoot2 + JDK8 + MyBatis-Plus + MySQL + EasyExcel
4. 关键能力：分表动态查询、CSV映射、动态表头导出、数据补0处理
